# isochron roadmap

The roadmap is derived from GitHub milestones, which are the single source of truth : no hard release dates are committed.

| Version | Theme | Status |
|---------|-------|--------|
| [v0.1.0](https://github.com/nubster-opensources/isochron/milestones) | Foundation | Shipped |
| [v0.2.0](https://github.com/nubster-opensources/isochron/milestones) | Ergonomics and extensions | Planned |
| [v0.3.0](https://github.com/nubster-opensources/isochron/milestones) | Extended scope (year field, iteration helpers, no_std) | Planned |

Milestones follow the naming format `vX.Y.0 - Theme` (example: `v0.2.0 - Ergonomics and extensions`), include a short description, and list the issues attached to that scope.
